BudgetWise — это высокопроизводительное и безопасное приложение для управления бюджетом. Оно заполняет пробел между простыми таблицами и сложными банковскими приложениями, предлагая синхронизацию данных в реальном времени, визуальную аналитику и профессиональную отчетность.

🌐 **[Демо-версия: BudgetWise на Vercel](https://budgetwise-kappa.vercel.app/)**

---

### 🚀 Ключевые особенности

- **Движок данных в реальном времени:** Бесшовная синхронизация с **Firebase Realtime Database** для мгновенного обновления данных на всех устройствах.
- **Визуальная аналитика:** Динамический обзор финансов с использованием **Chart.js** для визуализации соотношения доходов и расходов.
- **Профессиональная отчетность:** Функция **экспорта в PDF** одним кликом для создания подробного ежемесячного отчета.
- **Продвинутая фильтрация:** Хронологическая сортировка и детальный анализ привычек расходов по месяцам.
- **Современный UI/UX:**
  - **Темный/Светлый режимы:** Кастомное переключение тем на основе методологии BEM с сохранением предпочтений пользователя.
  - **Интерактивная обратная связь:** Интеграция **SweetAlert2** и **Toastify** для улучшения пользовательского опыта.
  - **Skeleton Loading:** Оптимизация воспринимаемой производительности во время загрузки данных.

---

### 🛠️ Технологический стек и архитектура

- **Core:** Vanilla JavaScript (ES6+) с упором на модульную архитектуру.
- **Безопасность:** Профессиональный конвейер сборки с использованием **Webpack 5** и **переменных окружения** (`dotenv`) для защиты конфиденциальных учетных данных API.
- **Backend:** Firebase (Auth и Realtime Database).
- **Стилизация:** CSS3 с использованием методологии **BEM** для создания поддерживаемого кода.
- **Деплой:** CI/CD конвейер через **Vercel** с автоматизированной сборкой продакшн-версии.

### 📦 Установка и настройка

Для локального запуска проекта вам необходимо настроить собственные переменные окружения:

1. **Клонируйте репозиторий:**
   ```bash
   git clone [https://github.com/Ahmed-Yehya84/budgetwise.git](https://github.com/Ahmed-Yehya84/budgetwise.git)
   cd budgetwise
   ```
2. Установите зависимости:

```bash
Установите зависимости:
```

3. Настройте переменные окружения: Создайте файл .env в корневом каталоге и добавьте свои учетные данные Firebase (эти переменные внедряются через Webpack во время сборки):

```
FIREBASE_API_KEY=ваш_api_key
FIREBASE_AUTH_DOMAIN=ваш_проект.firebaseapp.com
FIREBASE_DATABASE_URL=ваш_url_базы_данных
FIREBASE_PROJECT_ID=ваш_id_проекта
FIREBASE_STORAGE_BUCKET=ваш_проект.appspot.com
FIREBASE_MESSAGING_SENDER_ID=ваш_id
FIREBASE_APP_ID=ваш_id_приложения
```

4. Запустите сервер разработки:

```bash
npm start
```

### 📄 Экспорт в PDF и Темы

- **Отчетность:** Загрузите ежемесячный отчет о расходах в формате PDF, нажав на иконку PDF в футере. Он включает все отфильтрованные транзакции, визуальный график и финансовые итоги.
- **Переключение темы:** Переключайтесь между светлым и темным режимами. Ваши предпочтения сохраняются в `localStorage` и применяются автоматически при следующем посещении.

### 🧠 Стратегическая реализация

В этом проекте я сосредоточился на **чистом коде (Clean Code)** и **безопасности**. Благодаря внедрению системы сборки на базе Webpack, я гарантировал, что ключи API никогда не прописываются в исходных файлах, что предотвращает утечку учетных данных.

Приложение имеет модульную структуру, строго отделяющую **логику данных Firebase** от **компонентов рендеринга пользовательского интерфейса**. Такое разделение (decoupling) гарантирует, что кодовая база остается масштабируемой, тестируемой и простой в обслуживании при добавлении новых функций.
